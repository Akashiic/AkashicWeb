# Problem → fix matrix

> Every known problem from the research (issue trackers, code reading, spikes, reviews) mapped to its fix. Generated from the first plan (`research/raw/06-plan-kiosk-scope.json`) and **re-scoped on 2026-10-10** for the interactive-browser scope (DECISIONS D-002); rows N1+ come from the adversarial reviews and the scope change. Targets: **MVP** = must work on 2026-10-25; **Stretch** = aimed at 10-25 with a fallback ready; **After** = after the event; **Optional** = only for the optional relay path.
